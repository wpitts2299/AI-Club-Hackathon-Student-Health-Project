# AI-Powered Student Wellness Triage System

**Hackathon Prototype | Python • FastAPI • NLP • Machine Learning • REST APIs**

An independently developed hackathon prototype exploring how natural-language processing and machine-learning techniques could be used to categorize student wellness concerns and route simulated cases to appropriate resources.

The application combines a FastAPI backend with transformer-based NLP classifiers, REST API endpoints, role-based demo workflows, and a dashboard for reviewing simulated student submissions.

## Key Features

- NLP-based classification of student-submitted text into predefined wellness concern categories
- FastAPI backend with REST API endpoints
- Transformer-based text classification using Hugging Face models
- Role-based demonstration workflows for students and support personnel
- Dashboard for reviewing and managing simulated cases
- Automated testing and load-testing utilities
- Prototype alert and notification workflows
- Demonstration of application-level security concepts, including authentication and protected data handling

## Project Scope & Disclaimer

This project was developed as a **student hackathon prototype for educational and demonstration purposes**. It uses synthetic/demo data and is **not intended for clinical use, diagnosis, emergency response, or deployment in a production healthcare environment**.

The project explores software architecture, NLP classification, API development, authentication, and secure-data-handling concepts. Security-related functionality is intended to demonstrate technical concepts rather than represent a production-grade security implementation.

**This application is not HIPAA compliant or HIPAA certified, and no claim of HIPAA compliance is made.** A production system handling protected health information would require additional security, privacy, compliance, infrastructure, operational controls, testing, and professional review beyond the scope of this hackathon project.

## Technical Focus

The project was designed to demonstrate hands-on experience with:

**Backend Development:** Python, FastAPI, REST APIs  
**AI / Machine Learning:** NLP, transformer-based classification, Hugging Face  
**Data Processing:** pandas and supporting Python libraries  
**Software Engineering:** API design, testing, modular application architecture, and documentation  
**Security Concepts:** authentication, access control, and protected-data-handling concepts in a prototype environment

## Important Note

The system does not provide medical advice, make clinical diagnoses, or replace qualified mental-health professionals or emergency services. All users, accounts, scenarios, and data included with the project are intended for software demonstration and testing.
